# Fly Pixel Game 🪰

Пікс-арт 2D-симуляція мухи на робочому столі, чия поведінка керується
справжнім нейронним конектомом (клон [`snedea/flybrain`](https://github.com/snedea/flybrain),
~70 груп нейронів, dendrite accumulate → fire → runconnectome) замість
`Math.random()`. Голод, страх, втома, цікавість, груминг, політ,
приземлення, реакція на їжу/тепло/тарган/біль/дотик — усе виходить із
графу нейронів і синаптичних ваг, включно з реальною дофамін-гейтованою
асоціативною пластичністю (навчання уникати гарячу чашку й оголений
провід).

Гра — **один self-contained HTML-файл** (`fly-pixel-game.html`, усі
спрайти вшиті як base64), без збірки, без залежностей, без бекенду.
Відкривається напряму в браузері (`file://`) або з будь-якого статичного
хостингу.

> ⚠️ Якщо ти в git worktree гілки `full-connectome` (не тут, окремий
> каталог) — там до цього файлу підключено ще й повний ~139k-нейронний
> конектом через Web Worker (`data/`+`js/sim-worker.js`+
> `js/brain-worker-bridge.js`), і `file://` для НЬОГО вже НЕ працює
> (`fetch`/`Worker` блокуються під цим origin) — обов'язково через
> HTTP-сервер. Деталі — `HANDOFF.md` у тій гілці.

## Швидкий старт

```bash
# локально — просто відкрий файл, або підніми статичний сервер:
python3 -m http.server 8080
# → http://localhost:8080/fly-pixel-game.html
```

Ніякого `npm install`/збірки не потрібно.

## Деплой на Vercel

1. Заведи цей каталог у GitHub-репозиторій (`git init`, `git add`, `git commit`,
   запушити на `github.com/<user>/<repo>`).
2. На [vercel.com](https://vercel.com) → **Add New → Project** → імпортуй
   цей репозиторій. Framework preset: **Other** (це не Next.js/React-проєкт,
   Build Command і Output Directory лишаються порожніми — статичні файли
   деплояться як є).
3. `vercel.json` у корені вже налаштовує `/` → `fly-pixel-game.html`, тож
   гра буде доступна прямо на кореневому домені (`https://<project>.vercel.app/`),
   без потреби вказувати ім'я файлу в URL.
4. Готово — Vercel автоматично передеплоює на кожен `git push` у гілку.

Мобільна адаптація (viewport meta, масштабування canvas під ширину
екрана без зміни внутрішньої роздільності гри 380×680) вже в коді —
працює і на телефоні, і в десктоп-браузері.

## Структура репозиторію

- `fly-pixel-game.html` — уся гра (єдиний файл, що деплоїться)
- `assets/*.png` — вихідні спрайт-аркуші й растрова карта зон (для
  довідки/редагування анімацій; у рантаймі НЕ використовуються — усе
  вже вшите base64 в HTML)
- `vercel.json` — маршрутизація для деплою
- `HANDOFF.md` — **стан проєкту, архітектура, дорожня карта з чеклистом
  реалізованих і запланованих фіч.** Почни звідси, якщо продовжуєш
  роботу над проєктом у новому чаті.
- `CHANGELOG.md` — повна хронологія розробки сесія за сесією (кожен
  знайдений баг, кожне рішення з обґрунтуванням) — для деталей "чому
  саме так".

## Плани

Ця версія (~70 лумпованих груп нейронів) лишається "легкою" продакшн-
версією на гілці `main`. Повна модель на всіх ~139k нейронах FlyWire
(через Web Worker) уже НЕ окремий майбутній проєкт — вона активно
розробляється в git worktree гілки `full-connectome` того ж репозиторію
(Фаза 0+1 підтверджені 2026-09-16). Якщо спрацює — замінить цю версію
в `main`; якщо ні — гілку буде видалено. Деталі — `HANDOFF.md` у тій
гілці, розділ "🧪 Full-connectome experiment".
